# Artificial Intelligence Project - Data Preprocessing System

## 📋 Project Overview
A comprehensive data preprocessing system for cleaning and preparing the People Dataset for AI/ML applications.

## 🎯 Features
1. **Data Loading** - Load CSV dataset with 9 fields
2. **Data Exploration** - Analyze dataset structure and statistics
3. **Quality Analysis** - Detect missing values, duplicates, inconsistencies
4. **Data Cleaning** - Automated cleaning pipeline
5. **Data Export** - Save cleaned data for further analysis

## 📊 Dataset Fields
The system processes the following 9 fields:
- Index
- User Id
- First Name
- Last Name
- Sex
- Email
- Phone
- Date of birth
- Job Title
